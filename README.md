# For the best ex

Most tools that clean up AI writing only subtract. They strip the banned words, the
throat-clearing, the fake-profound closing line, and hand you back prose that is clean and
still reads as machine-written. Clean is not the same as human.

This skill does the subtraction, then does the part nobody does. It adds back the things
machine text never has: a first-person stance, an anecdote with an institution and a number
in it, an admission that you might be wrong, sentence lengths that swing from four words to
forty instead of sitting at a tidy eighteen, and the hedges like "probably" and "I think"
that polished output always strips out.

Forked from [no-ai-slop](https://github.com/petergyang/no-ai-slop) by Peter Yang, which is
the subtraction layer and is very good at it. Everything in layer two is new here.

## Use it

Paste this, fill in the two blanks, and send:

```
Use this repo https://github.com/kayomarz97/for-the-best-ex

Remove any sign that this text has been edited or generated by AI.
Keep the word count at ____ words.

<paste your text here>
```

You can edit that line to make it better. Tell it where the piece is going, since a forum
reply and a README want opposite things. Tell it your actual word ceiling. If you want the
full treatment, add "ask me the questions first" and it will interview you for the specifics
before touching anything.

## Install

Paste this into Claude Code, Codex, or whatever harness you use:

```
Install this skill globally: https://github.com/kayomarz97/for-the-best-ex
```

Then invoke it:

```
/for-the-best-ex

[your draft]
```

## Three modes

**Edit** is the default. You get the full edited draft plus a short What changed section.

**Detect** audits without rewriting. Ask "does this read as AI?" and you get every pattern
found, each with the line quoted. It also names what is missing, which is usually the more
useful half: no first person, examples with nothing specific in them, no hedging anywhere,
flat rhythm. It will not give you a percentage and it will not tell you whether a model
wrote it, because nothing can do that reliably.

**Humanise** is layer two on its own, for text that is already clean and still reads as
nothing. It will ask you questions. If you refuse to answer them it will tell you it cannot
help, which is the honest answer.

## Layer one, what it cuts

Roughly forty banned words and phrases, plus the sentence patterns. The ones worth naming:

| Pattern | Reads like |
|---|---|
| Binary contrast | "It isn't X. It's Y." |
| Tricolon | three parallel items of matching length |
| Participial tail | "..., highlighting the importance of" |
| Throat-clearing | "Here's the thing..." |
| Faux-insight setup | "What nobody tells you..." |
| Colon reveal | "The best part: it learns." |
| Importance puffery | "marks a pivotal moment" |
| Weasel attribution | "experts agree", "studies show" |
| Fake-profound kicker | the closing metaphor |
| Both-sidesing | equal space for an unequal question |

Em dashes are banned outright, zero anywhere in the body. That is stricter than the upstream
rule and stricter than any real style guide. The em dash is not actually proof of anything
and plenty of good writers lean on it, but it became a folk signal, so readers now react to
it whether or not that is fair. The rule removes a fight you gain nothing from winning.

## Layer two, what it adds

1. **First person with something at stake.** Not "clinicians often face difficulty during
   handover" but "I have never once finished a handover without dropping something."
2. **Anecdotes anchored in detail an outsider could not supply.** The institution, the grade
   of the person who said it, the time of night, the actual number, the local jargon, the
   rule that exists on paper next to the different rule everyone follows.
3. **Admitted uncertainty and admitted exposure.** The bar is whether you would wince
   slightly. If it is safe it is decoration.
4. **Uneven rhythm.** Sentence lengths in a paragraph should span at least 20 words end to
   end, with at least one under six.
5. **Kept informality.** Quite, probably, I think, a bit, to be fair. Contractions stay.
6. **Refused symmetry.** No three points of equal weight, no sections of matching length.

The skill will never invent any of this. If your draft needs an anecdote and you have not
given it one, it asks. A fabricated detail is worse than a flat sentence, and it is also the
one failure that would actually get you caught.

## Format profiles

Where the piece is going changes the rules, so the skill asks first.

Forum posts, comments, replies, DMs, and email get **no headers, no bullets, no numbered
lists, no bold labels**. Flowing prose only. Almost nobody types a markdown header into a
forum reply, and models do it constantly, so this single rule does more work than most of
layer one. Essays allow headers past roughly 1,200 words. READMEs keep their structure,
because structure is what a README reader wants. Academic submissions get layer one plus
whatever first person the venue permits, and the skill will tell you if yours permits none.

## What this does not claim

It does not claim to make anything undetectable, and you should distrust anything that does.
Detectors are unreliable in both directions: they miss machine text routinely, and they flag
genuine human writing at rates that have gotten real students in real trouble, with
non-native English writers hit hardest. Vanderbilt disabled Turnitin's AI detector over it.
OpenAI withdrew its own classifier for low accuracy. There is no ruleset that confers
undetectability, because there is no stable target to be undetectable against.

What is actually on offer is better than that. Writing that is specific, opinionated, and
grounded in things only you know is writing where the question stops being interesting. It
also happens to be the only kind worth reading.

There are no unicode tricks in here. No zero-width spaces, no homoglyph swaps, no Cyrillic
lookalikes, no deliberately inserted typos, no thesaurus laundering. They are trivially
caught by anything that normalises text, they make the writing worse, and unlike a clumsy
sentence they are unambiguous evidence of intent to deceive. See
[references/what-does-not-work.md](references/what-does-not-work.md).

Use it on your own thinking. Not for passing off work as yours where that is prohibited.

## Files

1. `SKILL.md`: the rules, in two layers, with the precedence order for where they conflict.
2. `eval.md`: pass/fail checks the skill runs on its own output, including countable ones.
3. `references/how-detection-works.md`: what the published research establishes.
4. `references/what-does-not-work.md`: the debunked tricks, and why they backfire.
5. `scripts/build_plugin.py`: builds the ChatGPT and Codex plugin ZIP.
