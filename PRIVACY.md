# Privacy

For The Best Ex is a skills-only plugin. It does not run an external server, require an
account, or collect, store, or sell personal data.

The text you provide is processed by whichever AI product you run the skill inside, such
as Claude, ChatGPT, or Codex. That processing is covered by the privacy terms of that
product, not by this repository.

The skill asks you for specific personal detail, because specificity is what makes writing
read as yours. Anything you type in response goes wherever your AI product sends it. Do not
paste patient information, anything covered by a confidentiality agreement, or anything you
would not want stored on someone else's server. Change identifying details before you paste
them, then change them back yourself afterwards.

Visiting the GitHub repository may create normal web server and analytics logs under
GitHub's policies.
